# IndependentWork11: LINQ-пайплайни, ETL та аналітика

Дисципліна: Об'єктно-орієнтоване програмування, самостійна робота №17.
Виконав: Висоцький Олександр, група ІПЗ-3/1.

Консольний застосунок для сценарію «Продажі»: генерує тестові дані та виконує чотири LINQ-пайплайни з вимірюванням часу.

| Файл | Призначення |
|---|---|
| `Models.cs` | Сутності `Sale`, `Product`, `Customer` та типи результатів пайплайнів |
| `DataGenerator.cs` | Генерація даних (60 продуктів, 80 клієнтів, 1000 продажів, `Random` із фіксованим seed) |
| `SalesAnalytics.cs` | Чотири пайплайни, кожен окремим методом |
| `Program.cs` | Запуск, вимірювання часу через `Stopwatch`, вивід результатів |

Опис пайплайнів, аналіз вимірювань і висновки: [REPORT.md](REPORT.md).

## Запуск

Для коректних вимірювань запускайте у конфігурації Release:

```bash
dotnet run --project IndependentWork11 -c Release
```
