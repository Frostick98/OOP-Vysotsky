# sw3v2: DatabaseConnection (IDisposable та патерн Dispose)

## Висновок про різницю між сценаріями

1. **`using`** — найнадійніший спосіб. `Dispose()` викликається автоматично при виході з блоку, навіть якщо всередині виникне виняток. З'єднання закривається детерміновано, у передбачуваний момент.
2. **Явний `Dispose()`** — ресурс звільняється в той момент, коли програміст викликає метод. Це працює, але якщо між створенням і викликом станеться виняток, а `try/finally` немає, `Dispose()` не буде викликано. Повторний виклик безпечний завдяки прапорцю `_disposed`.
3. **Без `Dispose()`** — ресурс звільняє лише деструктор (`Dispose(false)`), коли збирач сміття вирішить прибрати об'єкт. Момент невідомий і не контролюється програмістом (у демонстрації його примусово викликано через `GC.Collect()` та `GC.WaitForPendingFinalizers()`). Тому покладатися на деструктор не можна, він лише страховка. У `Dispose()` викликається `GC.SuppressFinalize(this)`, тому після явного звільнення об'єкт не потрапляє у чергу фіналізації.
